Detailed Description

Shared parametric-search loop and its injected strategies.

MaxParametricSolver and MinParametricSolver run the same loop: find the cycles at the current ratio, move the ratio to the best cycle ratio, and stop when no cycle improves it. Only two things vary, and both are injected here:

  • the direction policy (KeepSmaller for the maximum problem, KeepLarger for the minimum problem) decides which ratio wins and when to stop;
  • the search policy (HowardRound / AlternatingRound) produces the cycles of one round and owns its finder, so the policy maps persist across rounds.

Being a header of its own keeps digraph_detail.hpp free of any dependency on the finders, which include it in turn.
