Detailed Description

Clock Skew Scheduling (CSS) objectives as one min-ratio engine.

Single-parameter clock-skew scheduling, expressed as one minimum cost-to-time ratio cycle engine. Every member of the survey's family – minimum clock period, EVEN, PROP, and C-PROP – is the same parametric potential problem with a different (cost, time) column; they differ only in the graph that is built, not in the solver:

*   Problem   cost                          time
*   Min CP    -delay (setup) / +delay (hold) 1 (setup) / 0 (hold)
*   EVEN      delay                          1 / 0 (pass-through)
*   PROP      cost                           time
*   C-PROP    mu                             sigma
*

css_ratio() solves \(\min_C \sum \mathrm{cost} / \sum \mathrm{time}\) for any such columns and is the single code path shared by the wrappers.

Minimum cost-to-time ratio cycle over generic (cost, time) columns.

\[ \lambda^* = \min_{C} \frac{\sum_{e \in C} \mathrm{cost}(e)} {\sum_{e \in C} \mathrm{time}(e)} \]

This is the single code path for every CSS objective; the wrappers below only choose the (cost, time) columns. A cycle whose total time is zero is ignored (its ratio is \(+\infty\)).

Minimum feasible clock period.

Edges are timing_edge with type 's' (setup) or 'h' (hold). The smallest feasible period is the maximum cycle ratio, so it is computed as the negated minimum ratio of the transformed (cost, time) columns.
