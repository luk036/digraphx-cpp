Detailed Description

template<typename Edge, typename Ratio, typename CostTime>
class digraph_detail::CostTimeAPI< Edge, Ratio, CostTime >

Parametric API for edges described by a (cost, time) column pair.

\[ d_r(e) = c(e) - r \cdot t(e), \qquad r(C) = \frac{\sum_{e \in C} c(e)}{\sum_{e \in C} t(e)} \]

The minimum-cycle-ratio API and the CSS objectives are the same arithmetic with different column extractors, so it is implemented once here. A cycle with zero total time has an undefined ratio and maps to \(+\infty\) rather than dividing by zero.
